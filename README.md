# segundo-cerebro-bx
Um guia de informações e dicas no  Gemini Notebook sobre o competitivo de Beyblade X capaz de responder as principais perguntas sobre 
melhores combos, peças, lançadores, podendo ensinar e classificar melhores Beys e suas qualidades, ou utilizar de 
de componentes pré-definidos para dar dicar de combinações e peças. Este repositório foi criado com o intuito de aprendizado para entender, 
aperfeiçoar e estudar o uso do Gemini Notebook.

Utilizei das seguintes perguntas para entender a qualidade das respostas geradas:
Quais são os combos e peças de Beyblade X mais usados no competitivo ?
Atualmente comprei 2 beyblades, o Dran Sword e o Dark Perseus, qual o melhor combo entre eles para se fazer ?
quais são os principais tipos de lançamento ?
Com base nas peças que possuo atualmente qual seria a sua recomendação para os próximos 2 beyblades que devo comprar ?
Como funciona o sistema de pontuação nos torneios?
